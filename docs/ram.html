RAM map

The console has 2 KB of RAM and the game uses nearly all of it. Two things are on this page and they are kept apart: a cross-reference generated from every instruction in the traced code, and names written by hand, each with where the meaning was read. A byte with a cross-reference and no name is a to-do, not a mystery solved.

How to read the counts. "5r 2w 1m" is five reads, two writes and one read-modify-write (INC, DEC, shifts) in the traced code. An indexed access (LDA $0500,X) is counted on the array's base only, so the object slots show on the field's first byte. Code the trace has not reached is not counted: no accesses is not evidence a byte is unused. Status: confirmed = read from the code that uses it; checked = also matched to a savestate or a run of the code; lead = a reading of some uses, not settled.
