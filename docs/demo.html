Demo

Leave the title screen alone and the game plays itself. It is not a recording: the game builds a powered-up state, picks a random corridor, and feeds the ship button presses from a small table, held for random lengths of time.

How it starts

Not on a timer: the title music starts it. The title loop (bank 0 $835A) returns as soon as $0300 is non-zero, and song 1, the title theme, sets it itself: command $94 — “set global flag”, which ORs its operand into $0300 ($93DA) — stands at $9D06, at the end of the first channel's melody, just before its jump back to the start. The title's own countdown ($F0/$F1) leads somewhere else: to the story screen, “LONG AGO…”, and back.
  1. The title loop returns to the reset path, which calls the game setup, bank 0 $805B (entry $8003) — the same routine a real new game uses.
  2. With Start not held ($F7 bit 4) and outside the TGL game ($30 bit 1), the setup builds the demo state and sets $30 bit 7, the demo flag.
  3. $EB18 starts the game in a random corridor: $51 = $F9D1 AND $0F, so 0-15, where 0 is the opening flight.
  4. Every frame the ship's input is replaced (below).

The input it invents

Neither recorded keypresses nor an AI. $DAE1 (fixed-bank entry $C02D, called by the player's handler, bank 3 $8CF3) runs every frame. With $30 bit 7 set it counts a hold timer $F2 down; when it runs out it draws a new one, $F9D1 AND $0F + $18 — 24 to 40 frames — steps $F4 = ($F4 AND $1F) + 1 and loads the pattern $DB32,$F4 into $F3. Then, every frame, it writes $F3 into all four controller bytes: $F7/$F8 (held) and $F5/$F6 (just pressed) — so the fire buttons count as freshly pressed on every frame. The real controller has already been read by then; only its Start button matters ($F493).

The 32 patterns, in order

Entries 1-31 are $DB33-$DB51, and every one holds A and B — the gun and the selected weapon — with a direction or none. The index runs 1 to 32, so $DB32 itself is never read, and entry 32 is $DB52: the first byte of the tile decoder, the opcode $A5, which as buttons is A + Select + Down + Right. Select opens nothing, because $F493 skips the pause and status-screen check during the demo. The starting entry is random ($F4 = $F9D1 AND $1F, bank 0 $8170), and $F9D1 mixes the frame counter with RAM and ROM bytes, so no two demos play alike.

Last, $DB15 turns the d-pad into a direction for the ship, $32 = $DB22[d-pad], for the demo and a player alike: a 3 × 3 grid, 4 the centre, opposite presses cancelling.

How it ends

  • Its countdown runs out — $F0/$F1, set up with $F0 = $1C: at most $1C × 256 frames, about two minutes ($DAED).
  • The stage ends — any stage change with the demo flag set ($EBA2).
  • A real Start press ($F4A3).

Each is JMP $FF4A: back into the reset path and the title screen.

Not established. Everything here is read from the code; no savestate has been taken during a demo. Whether a demo ship can die, and what happens then, is not read.

Demo: the button patterns the attract mode holds data confirmed

bank7.tbl_DB32 · file 0x1DB42-0x1DB61 · 32 bytes · PRG bank 7 · CPU $DB32-$DB51

$DAE1 ($C02D, called by the player's handler, bank 3 $8CF3): while $30 bit 7 (the demo) is set, every time the hold timer $F2 runs out it takes $F2 = random AND $0F + $18 (24-40 frames, $F9D1), steps $F4 = ($F4 AND $1F) + 1 and loads $F3 = $DB32,Y with Y = $F4; every frame it writes $F3 into $F7/$F8 (held) and $F5/$F6 (new), replacing whatever the controllers said. So the demo is NOT a recording of a real game: it cycles through these patterns, starting at a random one ($F4 = random AND $1F, bank 0 $8170), each held for a random time. Y runs 1-32, so $DB32 itself (Y = 0) is never read and the real patterns are $DB33-$DB51, 31 of them, every one holding A and B (fire and the weapon) plus a direction or none. Y = 32 reads $DB52 - the first byte of the tile decoder, the opcode $A5 - which as buttons is A + Select + Down + Right; Select does nothing in the demo because $F493 skips the pause/status check when $30 bit 7 is set. The extent stays at the find-tables bound; the table proper is $DB33-$DB51.
